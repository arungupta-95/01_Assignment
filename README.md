# 01_Assignment
Instructor Effectiveness Modeling — EdTech Platform

Built a Machine Learning model to predict instructor 
effectiveness tiers (Low/Medium/High) using batch-level 
learner data.

- Performed EDA, outlier detection, correlation analysis
- Defined custom Effectiveness Score using weighted formula
- Aggregated batch data to instructor-level (120 instructors)
- Trained Random Forest Classifier — 92% accuracy
- Identified key features influencing instructor effectiveness

Tech Stack: Python, Pandas, Scikit-learn, Matplotlib, Seaborn
